```
E10: =IF(COUNT(H10,K10,N10,Q10)=0,"",SUM(H10,K10,N10,Q10))
F10: =IF(COUNT(I10,L10,O10,R10)=0,"",SUM(I10,L10,O10,R10))
G10: =IF(F10="","-",IFERROR(F10/E10,"-"))
J10: =IF(I10="","-",IFERROR(I10/H10,"-"))
```

Summary line (B4) formula:

```
="Indicators: "&COUNTA(A9:A80)&"  |  With Y1 target: "&COUNT(E9:E80)&"  |  With Y1 achievement reported: "&COUNT(F9:F80)&"  |  At or above 100% of Y1 target: "&COUNTIF(G9:G80,">=1")
```

**Data validation**

- type `list`, rule `"Incremental,Cumulative,Annual survey (not summed)"`, applies to `T10:T12 T14:T19`
- type `list`, rule `"Catfish,Tilapia,Catfish and Tilapia,Not applicable"`, applies to `D10:D12 D14:D19`
- type `decimal`, rule `0` (greaterThanOrEqual), applies to `H10:I12 H14:I19 K10:L12 K14:L19 N10:O12 N14:O19 Q10:R12 Q14:R19`; error: Enter a number of 0 or more. Leave blank if not due or not reported.
